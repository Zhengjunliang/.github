# Security

Report a vulnerability privately, never in a public issue: open the Security tab of the affected repository and choose **Report a vulnerability** (GitHub private vulnerability reporting, enabled on every public repository of this account). A repository with its own SECURITY.md may add what is specific to it.

A report names the repository, the steps that reproduce the problem, and what an attacker gains. A vulnerability in a third-party dependency goes to that project; one in GitHub itself goes to GitHub's bug bounty, https://bounty.github.com.
